# Neniの小天地｜N9＋N21 整合入口（v2）

此網站沿用前版整合入口的 CSS 色調與 iframe 分頁功能，修正頂部配置。

- 左：白雛菊 + Neniの小天地
- 中：Neniの歌單／Neniの存鑽存歌 切換按鈕，桌機固定水平置中
- 右：在原網站開啟 ↗，會隨目前分頁開啟 N9 或 N21
- 窄螢幕自動改為兩行：上方名稱／原站開啟、下方置中兩分頁，避免重疊。
- N9：https://lionliontomato.github.io/N9/
- N21：https://lionliontomato.github.io/N21/
- 保留第二個 iframe 點擊後才載入、鍵盤左右切換、白色雛菊 favicon。

## 部署
將 `index.html`、`daisy.svg` 放在 GitHub Pages 專案根目錄；不要只上傳 ZIP 壓縮檔。

注意：整合入口不能控制子網站自己的 favicon 或快取；若要修改 N9/N21 內部，需在各自網站專案進行。
